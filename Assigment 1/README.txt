COOKIE CLICKER - Unity 6000.6.9f1
Open Assets/Scenes/CookieClicker.unity and press Play.
Use a portrait Game view, such as 1080 x 1920.
Tap the cookie. Buy click/automatic upgrades. Cash Shop purchases are simulated.
Scroll to see all six packs. Progress resets each play session.

GameManager: points, upgrades and income each second.
UpgradeData: ScriptableObject settings and increasing prices.
UIWindow: fade/scale animations. ShopItem: demo purchases. SafeArea: phone safe area.
Upgrade assets are in Assets/ScriptableObjects.
To add a pack, duplicate a Pack under Cash Shop/Viewport/Content,
then change its label and ShopItem points. The scroll content resizes automatically.

Android: portrait, ARM64, Android 8 or newer.
APK: Builds/CookieClicker.apk. Rebuild using File > Build Profiles.
The scene is editable in the Hierarchy; Assets/Editor contains its setup utility.
Submission ZIP includes Assets, Packages and ProjectSettings; Unity regenerates caches.
